# Formulario de Pedido de Rosas 🌹

Este es un formulario web para tomar pedidos de arreglos florales (rosas) que redirige automáticamente los datos a WhatsApp.

## 📝 Características del formulario

- Selección de cantidad de rosas (25, 50, 75, 100)
- Selección de tipo de ramo (1, 2 o 3 colores)
  - Con opciones de color: rojo, blanco, rosa
- Opción para añadir girasol 🌻
- Opción para añadir billetes 💵 (12, 25, 50, 100)
- Opción de cinta con frase personalizada (hasta 50 caracteres)
- Botón para enviar el pedido vía WhatsApp

## 🚀 Cómo usar

1. Clona este repositorio o descarga el ZIP.
2. Modifica la línea de teléfono en `script.js`:

```js
const telefono = "520000000000"; // cambia por tu número real
```

3. Sube los archivos a tu repositorio de GitHub.
4. Ve a `Settings > Pages` y selecciona la rama `main` y la carpeta `/root`.
5. Accede a tu formulario en la URL que te da GitHub Pages.

## 🔗 Resultado final

Al llenar el formulario y dar clic en "Enviar pedido", se abrirá WhatsApp Web con un mensaje prellenado listo para enviar.
