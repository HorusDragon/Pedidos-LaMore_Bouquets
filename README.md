# Formulario de Pedido de Rosas

Este formulario está diseñado para tomar pedidos de arreglos florales y enviar el resumen por WhatsApp. Compatible con navegadores de escritorio y móviles.

## Cómo usar

1. Sube los archivos a un repositorio en GitHub.
2. Activa GitHub Pages desde Settings > Pages > Source: main, root.
3. Abre la URL generada para ver el formulario.
